# Campaign world canon

This `world/` directory holds facts established as true **for this table**. It is this campaign's evolving canon, not a copy of the published setting and not a substitute for root `world/`.

- **Root `world/`** (`world/` at the repository root) is **setting-wide** canon shared across tables: reusable locations, factions, NPCs, and lore that are true whether or not this campaign exists.
- **This campaign's `world/`** is **this table's** canon: what play and GM-established truths have made true here, including changes, clocks, and relationships that other tables should not inherit automatically.

Do not silently duplicate or overwrite setting-wide files. Link or cite root entries when this table uses them; record only the campaign-local state and divergences here.

## Canon policy

- Published setting content is source material until selected or established in play.
- Adventure preparation is not canon merely because it was written.
- A secret may be true in GM canon before players learn it; label its visibility clearly.
- A planned event becomes history only if it occurs.
- Conflicts are flagged before canon is changed; silent retcons are forbidden.
- Promote into these folders only what is established for this campaign.

## Index

- `locations/` - persistent places and their current state at this table.
- `factions/` - organizations, agendas, resources, and relationships as they stand here.
- `npcs/` - recurring non-player characters for this campaign.
- `lore/` - timelines, cultures, cosmology, and other shared facts true for this table.

Add links here when entries are created.
