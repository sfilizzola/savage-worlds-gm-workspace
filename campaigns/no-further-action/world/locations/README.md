# Campaign locations

Use `templates/location.md` for **persistent** places that remain true across this campaign's child adventures. Record current state for this table only.

Adventure-only situation details stay inside the child adventure unless play makes them lasting campaign canon. Do not treat unused prep as established geography.

Table maps: [`ashgrove_map_1984.png`](ashgrove_map_1984.png) (county / valley) and [`ashgrove_town_map_1984.png`](ashgrove_town_map_1984.png) (town inset, Sheet 2). Player-facing. Streets, doors, and reprint locks live in [`ashgrove.md`](ashgrove.md). Sheet 2 wins for addresses if the two prints disagree.
