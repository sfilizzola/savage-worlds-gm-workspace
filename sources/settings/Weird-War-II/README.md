Activate this module only by listing `Weird War II` in an adventure's `setting_modules`. It may contribute WWII setting material, gear, adversaries, themes, and supernatural content appropriate to the declared supernatural level. If its mechanics conflict with SWADE Fifth Printing, SWADE controls unless an explicit house rule says otherwise.
