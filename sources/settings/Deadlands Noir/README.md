# Deadlands Noir

- **Role:** optional Deadlands Noir setting and source module
- **Status:** inactive by default
- **Files:**
  - `DL-Noir.pdf` — core setting rulebook (145 pages)
  - `DL-Noir-Companion.pdf` — companion sourcebook (209 pages)
- **Publication generation:** predates SWADE; compatibility review is mandatory
- **SHA-256:**
  - `DL-Noir.pdf`: `aff773974e6c380d510386fe991176a3a5806bd7a3d5a72582f1e728a551530d`
  - `DL-Noir-Companion.pdf`: `fdeb53be0fcf84310ef6f6486488b2fd9f7097a14e37efc2586d2f8f7c776544`

Activate this module only by listing `Deadlands Noir` in an adventure's `setting_modules`. It may contribute Deadlands Noir setting material, gear, adversaries, themes, and supernatural content appropriate to the declared supernatural level. If its mechanics conflict with SWADE Fifth Printing, SWADE controls unless an explicit house rule says otherwise.
