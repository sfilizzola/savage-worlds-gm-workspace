# Sources

Store source material here as read-only dependencies. Adding a file does not activate it for an adventure.

## Categories

- `systems/` - permanent or selectable game-system rules.
- `settings/` - optional setting modules.
- `background/` - historical works, maps, texts, images, and research.

For each source, keep a nearby `README.md` or catalog entry with title, edition/date, role, scope, provenance, and known compatibility issues. Do not silently alter source files. When replacing an edition, keep the authority declaration in `rules/RULES.md` synchronized.
