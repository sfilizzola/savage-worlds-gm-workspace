# Rules

Workspace mechanical policy, not adventure prep.

| File | Use |
|---|---|
| [RULES.md](RULES.md) | Authority precedence and how to cite mechanics |
| [house-rules.md](house-rules.md) | Standing overrides. Inactive unless an adventure lists the ID |
| [rulings.md](rulings.md) | Dated interpretations of unclear cases |
| [gm-quick-ref.md](gm-quick-ref.md) | Core SWADE GM card (source text), one A4. Print [print/gm-quick-ref.pdf](print/gm-quick-ref.pdf) on white paper, or [print/gm-quick-ref_pf.pdf](print/gm-quick-ref_pf.pdf) on cream stock |

The SWADE PDF remains authority. This folder does not replace `sources/systems/SWADE/`. Adventure-specific GM cards (hydra trackers, tonight’s light, opposition) stay in that adventure’s `handouts/`.
