### Logic summary

```text
Premise job: kill any two of three hydra heads so this station cannot keep helping the southern front.

Problems already in play:
- live hydra (board, loft, books)
- Ward’s pack is stale (wrong DZ, Rathaus as false head)
- short winter night, thin garrison

Reachable paths:
- board via Altrathausplatz (independent of the dummy)
- loft via Grüner Turm / north-wall aerial (independent)
- books via Brandt / Nördlinger (independent)
- dummy Rathaus is a pressure and a twist, not a required path; cutting it does not count
- two of three required; wounded hydra can still scream

Conclusion: end states agree with these paths (hydra dead or not). Order is player-chosen. This is not a visit order.
```

## Warning signs

- [ ] One failed Notice, Persuasion, or Research roll can stop the story. **Cleared** — independent vectors; orientation is not a single Notice; dummy leftover is not unique.
- [ ] Most situations can be summarized as “enter room, fight enemies.” **Risk, not currently true** — fights are optional and thin. Becomes true if the table solves every pin with shooting. Keep methods other than assault visible.
- [ ] The plot only works if players make one specific choice. **Cleared** — dummy visit optional; any two heads.
- [ ] A named NPC, secret, or likely fight appears without quoted lines, a GM Note, or at-hand stats beside that situation. **Cleared** — Ward has lines, GM Note, and a non-combat Extra block.

- [x] Target **3–4 hours**, or a longer declared runtime with identified cuts down to 3–4 hours. **Declared 6 h.** 3–4 hour core is now named in `RUN.md`.

- [ ] Opening trouble within the first **10–15 minutes** of play (map-only briefing does not count as the opening). **Partial.** Briefing is calm by design. Jump is spectacle without stakes. Landing/orient is the first real trouble. Time-box the briefing. Do not add a fake ambush.
- [x] Roughly **4–6 substantial situations**, not a dungeon of rooms. **At 6 h.** Use the 3–4 hour core if the table is short. SP0+0b are the extra opening beats.
- [x] **One** twist or major complication. Dummy Rathaus. Missed DZ is opening trouble, not a second twist.
